# 七图文案工作模板

先填写工作信息和七页稿，审核后另存或更新为明确的 `v1`、`v2` 等版本。方括号是占位符，交付前替换。不要把模板说明、读者任务、设计说明、审核内容印在图上。
本模板用于内部自动制作与留档，默认不作为等待用户确认的中间交付。每个模型编号单独填写一份，不合并不同模型的七页内容、版本或审核记录。完成约定范围后，按 [delivery.md](delivery.md) 分别打包；单篇返回一条 ZIP 下载链接，多篇按编号数值升序各返回一条链接。

字段对应母版的版面位置，不代表模型必须有相同数量的因果步骤或案例。P2/P3可用结果或必要条件承接多出的节点；P4可靠案例只有三个时，第四行可放明确的共同模式或判断提示。结构保留，内容含义必须准确。

本模板中的 `assets/masters/` 路径均相对于Skill根目录，不相对于本文件、稿件目录或当前终端目录；生成调用前解析为绝对路径。
