# 七图视觉规范：049 实图母版

## 1. 当前生效的母版

用户已明确选择 049 白底系列，并要求七张参考图全部作为母版。本规范据此执行；旧黑底 HTML 规范仅保留为历史资料，不作为并行可选方案，也不与白底混搭。

用户当轮明确要求优先。七张实图母版约束版面，当前冻结文案约束文字和逻辑，历史提示词只提供不冲突的建议。内容与构图冲突时先解决映射；确需改文案时自动返回审核修订、更新冻结版本，再制作受影响页，不在出图时偷偷改字。

随包登记的七张母版原图均为 **1080 × 1440 px、3:4 竖版**；此登记不代表本次已查看。以下路径相对于 Skill 根目录；调用工具时必须解析为实际绝对路径。

| 成品页 | 必用母版 | 页面职责 |
| --- | --- | --- |
| P1 | `assets/masters/049-p01.jpg` | 痛点封面 |
| P2 | `assets/masters/049-p02.jpg` | 模型定义 |
| P3 | `assets/masters/049-p03.jpg` | 发生机制 |
| P4 | `assets/masters/049-p04.jpg` | 典型表现 |

每次制作前，通过文件工具实际查看全部七张母版，确认路径、顺序、内容、尺寸及可读性。不能只看 P1 就声称已检查整套，不能用文字描述代替参考图，也不能捏造缺失的图像资源。资产缺失时只核查包内路径与来源清单的校验值；仍缺失则报告具体文件，不扫描或回访桌面原路径，不生成替代母版。不启动桌面应用、操作浏览器或截取用户屏幕。

批量制作时，以上检查可在本批开始时完成并共享只读母版；每个编号的七页调用仍必须逐页实际传入对应母版。下文“本篇／本组”均指同一个模型编号，不能跨文章共用定稿或成图。

## 2. 整组必须延续的视觉语言

- **画布**：默认请求与母版一致的 1080 × 1440 px；3:4 竖版必须保持。旧提示词的 1200 × 1600、1242 × 1656 不再覆盖本轮母版尺寸。
- **底色与配色**：白或极浅灰底、蓝色主视觉、黑色粗体标题、灰色辅助说明；红/粉用于对比，黄色用于提醒。P4 沿用红橙黄绿行标识；P5、P6 的绿勾与红叉沿用母版。不得套用旧“只许蓝黑灰”限制。
- **字体层级**：延续对应母版的黑体大标题、蓝色小标题、黑色正文、灰色辅助字及局部加粗。以实图中的相对大小和占位为依据，不谎称已从位图识别出精确字体或字号。
- **页眉**：左上蓝底白字圆角条“{编号} {完整模型名称}”（编号不足三位补零，超过三位不截断）；中部“每天学习一个思维模型”；右上黑底白字圆角页码“{页码}/7”。沿用各页母版的位置、比例与边距。
- **页脚**：左侧“思维模型系列 · 带你把思考变得更清晰”，右侧“收藏起来慢慢看”；分隔线、书签符号等沿用对应母版，不另换整套样式。
- **卡片与线条**：沿用对应页的圆角、蓝色细边框、浅灰/浅蓝底、轻阴影、虚线、手绘箭头与下划线。页面之间可以不同，但都属于同一套视觉体系。
- **作者戳**：每页一个红色圆形邮戳，默认文字为“鬼子不言 / 制作 / {本次制作年份}”；按本次制作日期填写年份，用户明确指定时从其要求。继承该页位置、大小和轻微做旧感，不遮挡正文或贴裁切边缘。
- **图形**：延续简化信息图和手绘表达，替换为当前模型的图形。图形必须帮助理解机制；不能把 049 的锁、门、成功/失败箭头当成所有模型的必备符号。
- **留白与阅读**：保留母版的模块分区和呼吸空间；必要时先压缩冗词并完成文字修订流程，不能用缩小字号解决溢出。

## 4. 参考图绑定与实际生成

1. 读取当前可用的 imagegen 技能与工具说明；确认已取得完整七页定稿和七张母版。
2. 为每页准备独立生成指令，包含：该页母版路径、该页全部定稿文字、需要保留的构图、需要替换的主题元素、模型编号/名称/页码、作者戳文字及目标尺寸。
3. 使用当前可用的内置图像生成工具，**一页一次调用**。根据实时工具说明实际传入该页母版，例如支持 `referenced_image_paths` 时使用其绝对路径；不能仅在 prompt 中写“参考 049”，也不能臆造不存在的参数。工具无法接收所需参考图时记录该阶段受阻。
4. 每个编号先生成自己的 P1，自行检查名称、字号层级、构图、中文及尺寸；通过后继续该篇 P2—P7。无需新增逐页人工确认，已有授权范围内的检查与修正自行完成。
5. P2—P7 每页都必须传入各自对应的原始母版；必要时可额外传入同一编号已验收的 P1，辅助统一本组颜色、字体和线条。当前 P1 不能替代 P2—P7 母版，也不能覆盖它们的构图；不把另一编号的成品作为本篇辅助图。
6. 若修改某页，按工具要求传入待修改图及所需母版；编辑前实际查看待修改图。只修受影响页，再检查整组一致性；P1变化及其他页的复用规则见 [delivery.md](delivery.md)。
7. 不用纯文字模仿、脚本排版截图或拼图替代用户要求的七张参考母版生成流程。原始母版保持不变，成品另存。
8. P1验收通过后，P2—P7在工具允许时可并行生成，但仍须每页独立传入对应母版并逐页核对。工具偶发错误或局部质量问题自行合理重试；若相同错误连续3次仍无改善，停止该页的无效重复，保留合格页并记录具体阻塞，不把缺页包称为完整成品。

指令可采用以下结构；实际调用前替换所有变量：

```text
生成 P{页码}/7 一张独立小红书竖图，目标 1080×1440，比例 3:4。
第一张输入图是本页不可替换的 049-P{页码} 母版。
保留其构图区、相对字号、页眉页脚、卡片、线条、留白及邮戳风格。
将旧模型的全部专属文字、编号、案例、数字和主题图形换为以下内容。
本页职责：{职责}
模型：{编号} {完整名称}
页码：{页码}/7
作者戳：鬼子不言 / 制作 / {本次制作年份}
构图映射：{逐模块对应关系}
定稿文字：{该页完整定稿，含图中标签与结论}
主题图形：{帮助理解本模型的图形及正确箭头关系}
如另附同一模型编号的已验收 P1，仅用于统一颜色、字体及线条，不复制其页面布局。
中文必须完整准确；不得残留 049 的内容；不得拼页或生成多页拼图。
```

## 5. 生成后验收与交付

通过文件工具逐张查看实际成图，结合定稿和对应母版核查；不能只检查 prompt 或文件是否存在。生成工具返回包外保存位置时，仅读取其明确返回的本次文件并复制进该编号的交付目录，不扫描工具目录或桌面。

运行 `scripts/check_images.py` 时使用已安装Pillow的Python：脚本同时验证文件结构并完整解码像素，拒绝只剩文件头的伪图、截断文件及多帧文件。缺少Pillow属于未完成检查，不能降级为只读文件头后声称通过。默认像素目标差异是需记录的提醒；只有用户明确要求精确1080×1440时才启用 `--strict-size`，3:4及同组尺寸一致始终检查。

- **数量与格式**：七张独立图片，P1—P7齐全、顺序正确，无重复页、长图或九宫格。
- **母版使用**：确认七页调用记录各自有对应参考图，构图与本页母版能逐项对照；不是七张都套 P1。
- **文字**：模型编号、完整名称、页码、作者戳年份正确；标题、正文、图中标签、标点完整，无错别字、乱码、漏字、重字和其他模型残留。
- **内容**：与定稿逐项一致，定义、边界、方法、例子和箭头关系准确；不得因参考图改成 049 的逻辑。
- **P1专项**：遮住页眉后，仍能看到完整模型名和痛点问句；模型名达到大标题级，否则修正。
- **视觉**：通过文件工具查看全尺寸及手机宽度的离线缩小预览；正文能读，无溢出、裁切、重叠，邮戳不挡信息，整组背景、蓝色、字体层级及线条一致。只读预览不改变交付原图；不打开桌面应用、浏览器或发布编辑器。工具无法提供某项检查时如实记录，不冒称已完成。
- **尺寸**：读取成品实际像素，记录每张宽高并验证 3:4；只有实测为 1080 × 1440 才能如此报告。工具未按目标输出时如实说明实际尺寸，不能谎报，也不能擅自裁掉内容。比例不合格则继续修正，不标记验收完成。
- **文件**：使用 `xhs-{编号}-p01` 至 `p07` 命名，保留真实格式扩展名；各编号分别存入自己的 `images/`。本篇七张独立成图放入该编号的最终ZIP；整组预览可附加，但不能替代独立图片。

图片数量、实际尺寸、验收状态及问题记录放在包内清单和审核记录中。依照 [delivery.md](delivery.md) 打包并核验，正常完整交付时最终只给ZIP下载链接，不另发逐张图片、尺寸说明或确认问题。仅有生成指令、HTML、排版草案、生成中回执或未经检查的图片，不等于完成交付。
