# 小红书图片规范 v2.0

> **定位：** 小红书7页图片设计。只管视觉。
> **切分线：** 与小红书文案规范 v2.0互不交叉，文案规范管文字，图片规范管视觉。

---

## 一、基础参数


| 参数   | 值                                 |
| ---- | --------------------------------- |
| 画布尺寸 | 1200×1600px                       |
| 数量   | 7张                                |
| 字体   | Noto Sans SC（400/500/600/700/900） |
| 输出格式 | HTML（可截图为图片）                      |


---

## 二、三色体系


| 色名  | 色值                      | 用途                      |
| --- | ----------------------- | ----------------------- |
| 蓝   | #0066FF                 | 主强调色（编号、箭头、金句框、分割线）     |
| 黑   | #000000                 | 底色                      |
| 灰   | rgba(255,255,255,.4~.8) | 文字层次（标题用.4，正文用.7，次要用.5） |


**设计原则：** 蓝黑灰三色，不用其他颜色。案例标记色（红/橙/绿）仅用于P4案例页的左侧竖线和底色。

## 三、7页分配

| P2  | 核心翻转 | 俗知俗见→翻转1→翻转2→金句卡片        |
| P3  | 模型拆解 | 3步机制+箭头连接+底部总结           |
| P4  | 日常案例 | 🟥🟧🟩三层案例，左竖线+底色区分      |
| P5  | 模型边界 | 学习→入口→羊群，三段对比+底部边界句      |
| P6  | 落地方法 | ❓孤岛测试+⚖️判断区分+🔑行动钥匙      |
| P7  | 收束   | 核心提醒+翻转+追问+金句框           |

## 六、制作流程

1. 读取前一篇小红书图片HTML代码作为模板
2. 替换内容（文案、模型名、编号）
3. 调整案例页的颜色标记与文案对应
4. 检查7页的页面任务是否完整
5. 确认三色体系没有偏移（不引入新颜色）
6. 打包输出（xhs-0XX-p01 ~ xhs-0XX-p07）
