# 一、任务目标

这组图片的目标不是做学术海报，也不是堆知识点，而是让普通读者通过7张图，快速完成以下认知过程：

**被现实问题吸引**

↓

**知道模型讲什么**

↓

**理解它为什么发生**

↓

**认出自己何时会中招**

↓

**知道它不等于什么**

↓

**拿到可以执行的方法**

↓

**记住一句核心提醒**

整组图片应形成完整的阅读闭环，而不是7张彼此独立、逻辑松散的信息卡片。

---

# 二、输出要求

- 必须输出 **7张独立图片**
- 按照 **P1—P7** 顺序输出
- 每张图片只能呈现对应页面内容
- 不得将7页拼成长图
- 不得做成九宫格
- 不得少页或多页
- 每页必须独立成图
- 所有页面保持统一的视觉系统
- 图片适合手机端阅读、收藏和转发

建议比例：

**3∶4竖版**

建议尺寸：

**1242×1656像素**

# 三、整组视觉定位

整体风格：

**知识科普 / 小红书爆款图文 / 白底蓝色主视觉 / 粗体大标题 / 手绘感标注 / 卡通信息图 / 收藏感强 / 清晰易读**

整体气质：

- 干净
- 理性
- 克制
- 有知识感
- 有认知翻转感
- 不严肃沉闷
- 不过度花哨
- 不做复杂写实场景
- 不使用大面积炫光和渐变
- 不使用过多无意义装饰

推荐视觉系统：

- 白色或浅灰背景
- 蓝色作为核心主视觉色
- 红色或粉红作为重点对比色
- 黄色作为提醒、洞察、行动提示色
- 黑色粗体作为主标题色
- 浅灰色用于解释卡片、定义卡片、总结卡片
- 圆角卡片
- 手绘箭头
- 手绘下划线
- 虚线边框
- 卡通人物
- 简化图标
- 信息流程图
- 对比卡片
- 结论金句框

# 五、P1—P7固定内容结构

---

## P1｜封面：现实痛点 + 模型名称

### 页面作用

让读者在1秒内同时知道：

1. 这是哪个思维模型
2. 它在讲什么现实问题
3. 为什么值得继续看

### 必须出现

- {模型编号}
- {模型名称}
- {核心痛点标题}
- 一句现实场景或认知翻转
- 一个能直接表现模型冲突的主视觉

### 首页最高优先级规则

**模型名称必须在P1主视觉区中再次以大标题级信息清晰出现。**

不能只放在：

- 左上角编号条
- 页眉
- 小标签
- 角标
- 辅助说明

首页必须同时存在：

# **{模型名称}**

和

# **{核心痛点标题}**

两者都要进入主视觉区。

视觉层级可以是：

### 方案一

第一视觉重点：

**{模型名称}**

第二视觉重点：

**{核心痛点标题}**

### 方案二

第一视觉重点：

**{核心痛点标题}**

第二视觉重点：

**{模型名称}**

但无论采用哪一种，模型名称都不能退化成辅助信息。

### 推荐结构

```markdown
{模型编号} {模型名称}

{模型名称}

{核心痛点标题}

{现实场景或核心翻转句}
```

### 画面要求

使用一个直观场景表达：

- 同一信息被不同方式判断
- 大脑做出自动反应
- 人物在两个选项之间犹豫
- 同一件事出现不同结果
- 群体、身份、情绪、经验等因素改变判断

不要把首页做成知识目录。

首页重点是：

**问题感、冲突感、代入感。**

---

## P2｜定义：这个模型到底是什么

### 页面作用

让读者快速理解模型的核心含义。

### 内容结构

主标题建议使用：

# **{模型名称}到底是什么？**

或：

# **你以为是A，其实是B**

或：

# **你以为在做什么，其实发生了什么**

### 必须出现

- 一句话定义
- 模型最关键的判断条件
- 一个“不是／而是”结构
- 一个简化的心理链路或因果关系

### 推荐结构

```markdown
{模型名称}，就是：

{一句话定义}

不是：
{常见误解}

而是：
{真正机制}
```

### 画面要求

可采用：

- 左右对比卡片
- 不是／而是
- 输入／判断／结果
- 同一信息进入两条不同路径
- 定义卡片 + 简化插画

页面不要堆历史来源和学术定义。

读者看完P2，应能用一句人话复述这个模型。

---

## P3｜机制：它是怎么一步步发生的

### 页面作用

解释这个模型的心理机制。

### 内容结构

优先采用3步或4步链路：

# **步骤1 → 步骤2 → 步骤3**

例如：

- 看到信号
- 自动分类
- 调整判断
- 得出结论

### 必须出现

- 清晰编号
- 箭头连接
- 每一步的动作
- 每一步的心理变化
- 最底部的核心翻转句

### 推荐结构

```markdown
① {第一步}

② {第二步}

③ {第三步}

底部金句：
{推理没有停止，只是……}
```

### 画面要求

可使用：

- 大脑
- 标签
- 天平
- 放大镜
- 信任调节器
- 漏斗
- 盾牌
- 箭头链路
- 逐步变化的人物表情

重点不是“人突然失去理性”，而是：

**某种心理机制悄悄改变了判断过程。**

---

## P4｜表现：你可能也这样做过

### 页面作用

让读者在现实场景中识别模型。

### 内容结构

建议使用3个典型案例。

案例应来自普通读者熟悉的生活：

- 职场
- 消费
- 社交
- 学习
- 内容判断
- 团队协作
- 亲密关系
- 决策选择

### 推荐结构

```markdown
案例一：{场景一}

你以为：
{表面判断}

其实：
{模型正在起作用}

案例二：{场景二}

案例三：{场景三}
```

### 画面要求

采用三组：

- 上下排列卡片
- 左右对照
- 同一件事不同评价
- 同一行为不同解释
- 同一个人不同反应

每个案例只保留最关键的对照词。

不要写成长段案例。

重点表达：

**事情没有变，判断方式变了。**

---

## P5｜边界：它不等于什么

### 页面作用

避免把模型讲歪，澄清常见误解。

### 内容结构

优先采用三个“不等于”：

```markdown
❌ A＝这个模型

❌ B＝这个模型

❌ 反过来做＝摆脱这个模型
```

### 必须说明

- 哪些行为是正常判断
- 哪些条件出现时才属于这个模型
- 反过来走极端并不等于纠偏
- 真正的判断标准是什么

### 推荐底部问题

# **真正要检查的不是你有没有立场，而是你的标准有没有变。**

或：

# **你的判断会不会因为对象变了而改变？**

### 画面要求

可使用：

- 三张判断卡片
- 红叉
- 不等于符号
- 统一标准尺
- 同一证据面对不同对象
- 正常判断与偏误判断的对比

P5必须具有概念严谨性。

不能把：

- 有立场
- 有偏好
- 有经验
- 怀疑他人
- 参考群体

简单等同于认知偏误。

---

## P6｜方法：怎么识别和修正

### 页面作用

给读者可以立即使用的方法。

### 内容结构

优先设计成3步行动法。

例如：

# **动作1 → 动作2 → 动作3**

每一步必须是动词开头。

例如：

- 摘标签
- 拆内容
- 换位置
- 查证据
- 设标准
- 找反例
- 看基准
- 留后手
- 延迟判断

### 每一步必须包含

1. 一个动作名称
2. 一个具体问题
3. 一个视觉图标
4. 一个可立即执行的行为

### 推荐结构

```markdown
① {动作一}

问自己：
{问题一}

② {动作二}

把内容拆成：
{三个部分}

③ {动作三}

换一个条件再问：
{测试问题}
```

### 画面要求

适合收藏，结构必须简单。

可采用：

- 3步流程图
- 图标 + 标题 + 一句话
- 内容拆解卡片
- 红蓝人物交换位置
- 前后对照
- 行动清单

不要在P6临时增加第四、第五个方法。

宁可少，也要能执行。

---

## P7｜总结：最后记住这一句

### 页面作用

完成收束，形成记忆点。

### 内容结构

建议包含：

- 一个简短主标题
- 一句总结
- 一个反问句
- 一个核心金句框
- 一个自测问题

### 推荐结构

```markdown
{结尾主标题}

{模型最终提醒}

——蓝色短分隔线——

{反问句}

核心金句：
{结尾金句}

自测：
我是在……，
还是在……？
```

### 画面要求

- 增加留白
- 减少解释
- 减少人物
- 减少卡片
- 强化金句
- 形成结尾感
- 适合截图收藏

结尾金句应成为整组图片最容易被记住的一句话。

# 六、文字排版要求

## 1. 标题

每页主标题必须：

- 使用粗体大字
- 分成2—3行
- 不压缩成长句
- 不使用过小字号
- 不被装饰遮挡

## 2. 正文

正文必须：

- 短句
- 分段
- 一屏扫读
- 不出现大段说明
- 不为了塞字而缩小字号

## 3. 重点词

每页建议强化3—5个重点词。

可使用：

- 蓝色
- 红色
- 加粗
- 放大
- 下划线
- 圆圈
- 色块

不要在同一页同时使用过多强调方式。

## 4. 信息密度

单页应遵循：

- 一个主问题
- 一个核心结论
- 一个主要视觉隐喻
- 不超过3个主要信息块

---

# 七、插画与视觉隐喻要求

插画必须服务于概念，而不是单纯装饰。

优先使用：

- 大脑
- 放大镜
- 天平
- 尺子
- 漏斗
- 箭头
- 标签
- 对话气泡
- 盾牌
- 队伍
- 人物交换位置
- 红蓝两组人物
- 事实卡片
- 证据清单
- 对勾和问号

画面必须表达机制。

例如：

- 不是只画两个人争论
- 而是画“同一句话进入两套判断标准”
- 不是只画一群人
- 而是画“人群如何改变个人判断”
- 不是只画大脑
- 而是画“大脑如何从输入走到结论”

---

# 八、颜色使用规范

## 蓝色

用于：

- 模型核心概念
- 方法
- 事实
- 证据
- 结构
- 主要卡片

## 红色或粉红色

用于：

- 对比
- 警示
- 另一种判断
- 错误路径
- 核心冲突

红色不代表邪恶。

蓝色也不代表正确。

如涉及两个阵营或两类人，需在不同页面适当交换红蓝位置，避免形成固定价值判断。

## 黄色

用于：

- 洞察
- 提醒
- 灯泡
- 行动
- 下划线
- 次级重点

---

# 九、人物与场景规范

人物应保持：

- 中性
- 友好
- 卡通化
- 抽象化
- 无现实身份指向
- 无攻击性表情
- 无夸张污名化

不得使用：

- 现实政治人物
- 国家或政党符号
- 宗教符号
- 民族标签
- 地域标签
- 性别刻板印象
- 职业歧视
- 群体污名化
- 暴力或武器

所有场景只服务于：

- 判断
- 选择
- 信任
- 推理
- 认知
- 决策
- 行为

# 十、作者戳规范

7张图片每页都添加作者戳。

作者戳统一文字：

# **{作者戳文字}**

例如：

**鬼子不言制作 2026**

要求：

- 红色圆形邮戳
- 轻微做旧
- 清晰可辨
- 每页只出现1次
- 不遮挡主标题
- 不遮挡关键正文
- 不遮挡人物面部
- 不贴近裁切边缘
- 7页位置可变化，但样式统一

---

7张图片必须使用同一套：

- 字体体系
- 标题字号逻辑
- 正文字号逻辑
- 页眉结构
- 页脚结构
- 页码样式
- 卡片圆角
- 卡片边框
- 卡片阴影
- 主蓝色色值
- 对比红色色值
- 背景色
- 插画语言
- 图标语言
- 箭头语言
- 下划线语言
- 作者戳语言

页面可以有变化，但不能像7套模板。

# 十二、中文准确性要求

生成前必须逐页检查：

- 编号正确
- 模型名称正确
- 页码正确
- 标题完整
- 定义准确
- 箭头方向正确
- 标点完整
- 引号完整
- 不出现错别字
- 不出现乱码
- 不出现漏字
- 不出现重复文字
- 不出现参考模型名称

参考图片中的文字只能作为版式参考，不得进入最终图片。

# 十三、逐页强制检查清单

## P1

- 是否出现模型编号
- 是否出现完整模型名称
- 模型名称是否进入主视觉区
- 模型名称是否不仅出现在页眉
- 是否出现核心痛点标题
- 是否一眼看懂这篇讲什么
- 是否有明确视觉冲突

## P2

- 是否用一句话讲清定义
- 是否有“不是／而是”
- 是否突出模型真正判断条件
- 是否避免学术化堆砌

## P3

- 是否有明确步骤链路
- 是否有编号和箭头
- 是否说明机制如何发生
- 是否有核心翻转句

## P4

- 是否有3个典型场景
- 是否来自普通生活
- 是否强化对照词
- 是否避免长段案例

## P5

- 是否澄清常见误解
- 是否说明正常判断与偏误的区别
- 是否避免概念扩大化
- 是否给出真正判断标准

## P6

- 是否有3个可执行动作
- 每一步是否是动词
- 是否有具体自问句
- 是否适合收藏执行

## P7

- 是否减少信息密度
- 是否有明显收束感
- 是否有核心金句
- 是否有最终自测
- 是否形成记忆点

---

# 十四、生成后验收标准

生成完成后，必须进行一次整组复检。

## 内容复检

- 7页顺序是否正确
- 每页功能是否明确
- 页面之间是否逻辑连续
- 是否遗漏核心定义
- 是否遗漏方法
- 是否遗漏结尾金句

## 视觉复检

- 7页是否像同一套系列
- 标题是否清晰
- 手机缩略图下是否可读
- 页面是否过密
- 插画是否真正解释概念
- 重点是否过多
- 留白是否足够

## P1专项复检

必须回答四个问题：

1. 不看正文，能否看到模型名称？
2. 不看页眉，能否知道模型叫什么？
3. 能否同时看到模型名称和痛点标题？
4. 模型名称是否属于大标题级信息？

任何一项为“否”，P1均视为不合格，必须重新生成。

# 十五、最终执行指令

请严格按照以下顺序输出：

- P1：痛点封面
- P2：模型定义
- P3：发生机制
- P4：典型表现
- P5：边界澄清
- P6：应对方法
- P7：总结金句

必须满足：

- 共7张
- 每张独立
- 不拼图
- 不漏页

{模型名称}

7页是否保持统一视觉体系。

必须输出7张独立图片，不得拼成长图，不得少页或多页。
