# 小红书文案规范 v2.0

> **定位：** 小红书文字内容的完整规范——标题+文案+排版。  
> **切分线：** 只管小红书文字内容，图片设计归小红书图片规范 v2.0。

---

## 一、小红书标题规范

### 1.1 字数限制

- 20字以内（含标点和emoji）
- 超过20字会被截断，影响点击率

### 1.2 钩子句式

- 从核心翻转推导，用问句或反常识句
- 不用模型学术名做标题主体，用读者能秒懂的场景/痛点
- 格式：`[模型名]｜[钩子问句]`

### 1.3 emoji使用规则

- 标题末尾不加emoji
- 标题中不使用emoji
- 标题保持纯文字的干净感

### 1.4 示例


| 模型   | 标题                   |
| ---- | -------------------- |
| 从众效应 | 从众效应｜你真的同意了吗？        |
| 羊群效应 | 羊群效应｜队伍一长，你就觉得值得跟？   |
| 达克效应 | 达克效应｜为什么刚懂一点，就敢指点全局？ |

## 二、小红书文案内容规范

### 2.1 七模块结构


| 模块        | 内容             | 标记     |
| --------- | -------------- | ------ |
| ① 定义+公式   | 1-2行定义 + 箭头链公式 | —      |
| ② 钩子→俗知俗见 | 故事引入 + 常见误解    | —      |
| ③ 机制拆解    | 2-3步，短句标题      | —      |
| ④ 案例三层    | 极端版/日常版/自我版    | 🟥🟧🟩 |
| ⑤ 落地方法    | 问自己/做区分/给动作    | ❓⚖️🔑  |
| ⑥ 翻转收束    | 核心金句 + 追问      | —      |
| ⑦ 标签      | 5个（3固定+2变量）    | #      |


### 2.2 字数与行宽

- 总字数：800字以内
- 每行≤20字
- 短句为主，不用逗号连成长句

### 2.3 案例三层标记


| 标记  | 层次  | 说明                 |
| --- | --- | ------------------ |
| 🟥  | 极端版 | 大幅度、戏剧性的案例（如泡沫崩盘）  |
| 🟧  | 日常版 | 读者日常会遇到的场景（如网购看销量） |
| 🟩  | 自我版 | 读者自己可能正在做的事（如跟风报课） |


### 2.4 落地方法标记


| 标记  | 含义  | 内容              |
| --- | --- | --------------- |
| ❓   | 问自己 | 一个让读者自检的问题      |
| ⚖️  | 做区分 | 帮读者区分“该跟”和“不该跟” |
| 🔑  | 给动作 | 一个明天就能做的具体动作    |


### 2.5 文案内容教训（029-041迭代）


| 教训                     | 说明                                                                            |
| ---------------------- | ----------------------------------------------------------------------------- |
| 公式末环回扣核心翻转             | 公式最后一环要点题（029：“队伍变成证据”；030：“身份变成证据”）                                          |
| 机制标题短促化                | 机制步骤用3-4字短句标题（029：看见行动/开始推断/放下判断；030：看见权威符号/简化判断任务/跳过追问）                      |
| 🟩收束句有“进去之后能出来”的视角     | 自我版案例不只说“你也会这样”，还要说“怎么出来”                                                     |
| 🔑确认三件事要具体             | 不说“多想想”，说“证据够不够、风险扛不扛得住、退出条件想好没有”                                             |
| ⚖️做区分用委托vs放弃句式         | 落地方法的“做区分”可以用“委托判断vs放弃判断”的对比句式，比“该跟vs不该跟”更精准（030）                             |
| 🟩自我版含“进去容易出来也容易”      | 自我版不只说“你也会这样”，还要给一个“出来”的动作——一句话的出口（030：“问一句：他说的依据是什么？”）                       |
| ⚖️做区分用“委托vs放弃”句式验证通过   | 034验证：委托态度回答做判断vs放弃态度答案看行为证据，对比句式清晰有效                                         |
| 🔑确认三件事要具体验证通过         | 034验证：确认三件事（他说的是态度还是行为？有没有行为证据能交叉验证？这个场景允许他说真话吗？）具体可执行                        |
| 避免道德化表达                | 小红书文案同样不用“说假话”“装”“骗人”，用“修饰”“被场景塑造”“答案被社会期待过滤”（034）                            |
| 全篇母题词贯穿                | 小红书文案也围绕一个母题词展开，公式末环、翻转收束都回扣母题词（034：“标准答案”）                                   |
| 🟩“出来方法”换问法验证通过        | 036验证：🟩自我版的“出来方法”不一定要给行动指令，换一个问法也能让读者从压力中出来——“如果出问题，最可能因为什么？”比“你应该反对”更安全也更实用 |
| ⚖️做区分“健康共识vs表面一致”验证通过  | 036验证：落地方法的做区分用“充分讨论后的健康共识 vs 靠压力压出来的表面一致”对比，清晰有效                             |
| 机制4步验证通过               | 036验证：机制步骤4步（权威先定调/反对变冒犯/风险被压回去/沉默被当同意）标题短促化，每步1-2行说明，节奏紧凑                    |
| 误区页用❌三连比✓⚠✗更直觉         | P5误区页用❌三连排比（如❌观点强烈=群体极化/❌意见一致=群体极化/❌中立才叫理性）比✓⚠✗三段对比更直觉、更有冲击力                  |
| 方法页给具体动作而非抽象问题         | P6落地方法的🔑行动钥匙必须给具体动作（如“先别跟一句更狠的，找一个高质量反方观点认真看完”），不能只给抽象问题（如“你有没有验证过”）         |
| 公式末环回扣核心翻转再次验证         | 036验证：公式末环“一致通过变成陷阱”直接回扣核心翻转“没人反对≠没问题”                                        |
| 🟥🟧🟩案例顺序可调整为日常→职场→深层 | 040验证：🟥日常小事→🟧职场/关系→🟩更深层影响，从轻到重递进，比极端→日常→自我更贴合某些模型                          |

## 三、小红书文案排版规范

### 3.1 换行节奏

- 每行≤20字，短句为主
- 短句独立成行，不用逗号连成长句
- 关键翻转句独立成段，前后空行
- 排比项每条独立成行，不用分号

### 3.2 emoji位置


| 位置     | 规则                  |
| ------ | ------------------- |
| 模块标题行  | 可加emoji（🧠💬🚪🧩🔑） |
| 案例标记   | 固定使用 🟥🟧🟩         |
| 落地方法标记 | 固定使用 ❓⚖️🔑          |
| 正文段落内  | 不加emoji             |


### 3.3 段落间距

- 模块之间用 `---` 分隔线
- 模块内部用空行分段
- 排比项每条独立成行

### 3.4 标签格式

- 放在文案最末尾
- 5个标签：3固定 + 2变量
- 固定标签：`#思维模型` `#认知升级` `#心理学`
- 变量标签：与具体模型相关（如 `#羊群效应` `#决策`）

### 3.5 强调方式

- **不用加粗**（小红书不支持Markdown加粗）
- 用独立成段+上下空行制造视觉重点
- 关键句放在段末，自然成为视觉锚点

## 四、完整文案模板

```
[模型名]｜[钩子问句]

---

🧠 [定义]
[1-2行定义]

[公式：A → B → C → 核心翻转词]

---

💬 [钩子→俗知俗见]
[故事引入2-3行]

[常见误解1-2行]

[翻转句独立成段]

---

🚪 [机制拆解]

[步骤1短句标题]
[1-2行说明]

[步骤2短句标题]
[1-2行说明]

[步骤3短句标题]
[1-2行说明]

---

🧩 [案例三层]

🟥 [极端版]
[2-3行]

🟧 [日常版]
[2-3行]

🟩 [自我版]
[2-3行，含"怎么出来"的视角]

---

🔑 [落地方法]

❓ [问自己的问题]
[1行]

⚖️ [做区分]
[1-2行]

🔑 [给动作]
[确认三件事：证据够不够、风险扛不扛得住、退出条件想好没有]

---

[翻转收束金句]
[追问句]

#思维模型 #认知升级 #心理学 #[模型名] #[变量标签]
```
